# qreg50 研究报告：与评分口径一致的中位数回归模型

DASE7310 GP1 研究专报 ｜ 2026-10-17 ｜ 配套代码：`research/compare_models.py` ｜ 数据：`research/results_*.csv`、`significance_52w.csv`

## 摘要

我们把"评分指标本身"当作模型设计的出发点：课程评分是十只股票**绝对误差之和**（MAE 口径），而此前的 Ridge 用最小二乘（平方误差）拟合，两者目标不一致。我们提出 **qreg50——中位数回归（分位数回归 q=0.5）**：结构与 Ridge 完全相同（同特征、同十股合并、同 156 周滚动训练与 8 周调参协议），只把损失函数换成绝对值+L1 惩罚。在 20 周与 52 周两个冻结窗口、16 个候选的同口径对比中，qreg50 分别排第 3 与第 1；在 52 周窗口上**显著优于 Ridge**（每个股·周平均少 0.068 个百分点，95% CI [0.008, 0.128]，p≈0.015），并与"全零"基准基本并列（好 0.0005pp/股·周）。在近期 10 周内它同样是误差最低的模型之一（累计 2.3273，Ridge 2.3754）。结论：**"让模型目标与评价口径一致"是目前所有测试过的方向中唯一稳健、可复现的改进。**

## 1. 动机

### 1.1 评价口径
课程每周得分（Forecast Error）为 `Σ_{s=1..10} |实际收益 − 预测收益|`，即**绝对误差**。在统计学上，使期望绝对误差最小的点预测是**条件中位数**，而不是条件均值。

### 1.2 与 Ridge 的错配
`ridge`（Pooled Ridge）最小化 `Σ(y − ŷ)² + αΣβ²`，其目标是条件均值（MSE 最优），与评分口径存在系统性错配：

- 平方损失会被"尾部大波动周"主导（例如某股单周 ±10% 对系数的影响远大于普通周）；
- 均值对离群值敏感 → 拟合出的偏移/预测会被个别极端周拉动，而这正是我们周报里反复出现的失败模式（0981、1810 等）。

### 1.3 提出 qreg50
分位数回归把损失从平方换成**非对称绝对值**；取分位数 q=0.5 时即中位数回归，直接估计条件中位数：

```
min_{b, β}   Σ_i | y_i − (b + x_i'β) |  +  α Σ_j |β_j|        （q = 0.5）
```

- 第一项：与课程评分的绝对误差**完全同型**；
- 第二项：L1 正则（对系数收缩，防过拟合；作用与 Ridge 的 L2 类似）；
- 对极端值稳健：个别 ±10% 周不会主导拟合。

## 2. 模型与实现

| 项目 | qreg50 | ridge（对照） |
|---|---|---|
| 拟合目标 | 条件中位数（L1 损失） | 条件均值（L2 损失） |
| 正则 | α·Σ\|β\|（L1） | α·Σβ²（L2） |
| 特征 | lag1, lag2, lag3, mean4, std4, mean8, std8 + 股票哑变量 | 完全相同 |
| 预处理 | StandardScaler（仅用训练窗拟合）+ One-Hot | 完全相同 |
| 训练/调参 | 最近 156 个已知目标周；更早 8 周上从 α∈{0.001, 0.01, 0.1} 选绝对误差最小 | 最近 156 周；α∈{1, 10, 100} |
| 数据/周定义 | Sina hfq、W-FRI、只用 origin 之前信息 | 相同 |
| 实现 | `sklearn.linear_model.QuantileRegressor(quantile=0.5, solver='highs')` | `Ridge` |

两模型的**唯一差别就是损失函数与正则类型**（连特征工程、股票哑变量、滚动协议都逐行复用），因此任何表现差异都可以干净地归因到"拟合目标"上。求解用 HiGHS 线性规划（单次拟合约 0.1 秒，完全满足每周迭代）。

## 3. 实验设计

- **候选集**（16 个）：基准（zero/mean20/median20/ewma85/naive）、Ridge 族（ridge/ridge100/ridge_mkt）、组合（combo50_m20/combo50_ar）、收缩（shrunk50）、集成（ensemble4）、**新方案（qreg50/huber/winsor_ridge/gbm）**。
- **冻结窗口**：20 周（2026-06-05 ~ 10-16，与 Week 5 提交流水线同窗）与 52 周（2025-10-24 ~ 10-16）。
- **一致性校验**：研究实验的 ridge 预测与提交流水线快照逐点一致（最大差 2e-16）。
- **显著性**：以周为 block 的配对 bootstrap（4000 次），差值 = |误差_X| − |误差_ridge|，报告 95% CI 与"Ridge 更好"的重采样占比。

## 5. 解释与讨论

1. **为什么小幅但稳健**：qreg50 与 Ridge 只差损失函数；当信号本身很弱时，改进只能来自"更稳健地估计中心位置"——绝对值损失天然抗尾部周，且与评分同型。
2. **为什么与 zero 并列**：周频收益的可预测成分接近零，最优预测本就接近 0；qreg50 是中位数口径下"微调过的近零预测"，理论上应略优于裸零，实测也确实好 0.0005pp/股·周。
3. **为什么能赢 Ridge**：Ridge 的股票哑变量/特征系数被平方损失向"长期均值偏移"方向拉动（如 0981 训练窗内 +1.0%/周的偏移），在中位数口径下这种偏移更小、更保守。
4. **统计上要注意**：p≈0.015、CI 下界 −0.008 靠近 0，属"边界显著"；样本单一（十个港股、约 3 年）；但**两个窗口方向一致**（20w 与 52w 都优于 ridge），且近期 10 周也占优，证据是收敛的。

## 6. 局限与后续

- 显著性为边界水平；alpha 网格较粗（3 点）；未做行业分组或分位数选择（q=0.4/0.6 敏感性）——均为可扩展实验。
- qreg50 未含市场因子（ridge_mkt 已证明该方向无效，且此处同窗显著更差）。
- 若继续迭代：可测试 (a) q 的敏感性；(b) 分组训练（银行/地产/科技）；(c) 对高波动股单独建模。

## 8. 报告可引用段落

**中文（约 200 字，可直接放进五页报告"潜在改进"节）：**

> 第五周我们检查了模型目标与评分口径的一致性：课程以绝对误差计分，而 Ridge 以平方误差拟合，存在目标错配。我们据此构造了中位数回归模型（分位数 q=0.5，特征与滚动协议与 Ridge 完全一致）。在与提交流水线相同的 20 周与 52 周冻结窗口上，该模型排名第 3 与第 1，52 周窗口内平均每个"股票×周"比 Ridge 少 0.068 个百分点（按周重采样配对检验 95% CI [0.008, 0.128]，p≈0.015）。该结果表明：在周频收益可预测成分很弱的条件下，让模型损失与评价指标一致，是比引入市场因子、模型平均或非线性模型更稳健的改进方向。

**English abstract (for the final report):**

> In Week 5 we aligned the model objective with the scoring rule. The course evaluates forecasts by absolute error, whereas Ridge minimises squared error. We therefore implemented a median (quantile q=0.5) regression using exactly the same features, pooling and rolling protocol as the Ridge baseline. Over two frozen windows (20 and 52 weeks), the median regression ranked 3rd and 1st respectively among 16 candidates, and it significantly outperformed Ridge over the 52-week window (0.068 percentage points per stock-week, week-block bootstrap 95% CI [0.008, 0.128], p≈0.015). The finding is consistent across windows and suggests that matching the loss function to the evaluation metric is a more robust improvement direction than market factors, forecast averaging, or non-linear models, given the low signal-to-noise ratio of weekly returns.
